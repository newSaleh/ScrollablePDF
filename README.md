# ScrollablePDF

قارئ كتب PDF بسيط يعمل بالكامل داخل المتصفح (بدون خادم أو رفع للملفات لأي مكان)، مخصص للقراءة الطويلة بتمرير عمودي فقط.

افتح `index.html` مباشرة، أو فعّل GitHub Pages لهذا المستودع (الإعدادات ← Pages ← اختر الفرع المناسب) ليصبح متاحًا كصفحة ويب.

## المزايا

- **تمرير عمودي متواصل فقط** — لا يوجد وضع تصفح أفقي.
- **تحميل تدريجي (Lazy loading)** — لا يتم رسم كل صفحات الكتاب دفعة واحدة، بل فقط الصفحات القريبة من منطقة العرض، ويتم تحرير الصفحات البعيدة تلقائيًا لتوفير الذاكرة.
- **نطاق صفحات مخصص** — يمكن تحديد عرض من صفحة إلى صفحة (الافتراضي: الكتاب كاملًا).
- **تحكم بحجم الصفحة (تكبير/تصغير)** من ~1% حتى 100% (بعرض الشاشة كاملًا)، مع أزرار +/- إلى جانب الشريط لتحكم أسهل باللمس، بدون أي تمرير أفقي.
- **تمرير تلقائي (Auto-scroll)** بسرعة قابلة للتعديل من بطيء جدًا إلى سريع جدًا (مع أزرار +/-)، يتوقف تلقائيًا عند لمس الشاشة أو التمرير يدويًا.
- **وضع ملء الشاشة** مع إخفاء تلقائي للشريط العلوي، ويظهر فقط عند اللمس أو الضغط.
- **الوضع الليلي** لقراءة مريحة قبل النوم.
- **مؤقت نوم** — يوقف التمرير التلقائي بعد مدة تحددها (افتراضيًا 20 دقيقة).
- **يتذكر الكتاب وآخر صفحة** — الكتاب يُحفظ في هذا الجهاز (IndexedDB) ويُفتح تلقائيًا في المرة القادمة دون الحاجة لرفعه من جديد، ويعود بك تلقائيًا لآخر صفحة كنت فيها.
- **الانتقال إلى صفحة محددة** — اضغط رقم الصفحة أعلى الشاشة لفتح مربع للانتقال المباشر إلى أي صفحة، مع خطوة تأكيد قبل التنفيذ لتفادي الانتقال بالخطأ.
- **إضافة إلى الشاشة الرئيسية على الآيفون** — تفتح كتطبيق مستقل بدون أي شريط متصفح، ملء شاشة حقيقي 100%.
- مصمم ليعمل بسلاسة على الجوال، وخصوصًا آيفون/سفاري (دعم `safe-area`، ومنع التكبير غير المقصود، وارتفاع شاشة صحيح عبر `dvh`).

## الاستخدام

1. افتح الصفحة.
2. اختر ملف PDF (أو اسحبه وأفلته) — يُحفظ تلقائيًا ليفتح من تلقاء نفسه في كل زيارة قادمة.
3. اضبط الإعدادات (⚙️) حسب رغبتك: حجم الصفحة، نطاق الصفحات، سرعة التمرير، الوضع الليلي، مؤقت النوم.
4. اضغط ⛶ لوضع ملء الشاشة أثناء القراءة، واضغط ▶️ لتفعيل التمرير التلقائي.
5. اضغط رقم الصفحة أعلى الشاشة للانتقال المباشر إلى أي صفحة أخرى.

جميع الإعدادات (الحجم، السرعة، الوضع الليلي، مدة مؤقت النوم) والكتاب نفسه وآخر صفحة مفتوحة، كلها تُحفظ محليًا في متصفحك على هذا الجهاز فقط.
